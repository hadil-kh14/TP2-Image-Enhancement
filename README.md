# TP2 - Image Enhancement App

## 📌 Description
This project is a graphical application developed using Python, PyQt5, and OpenCV.  
It allows users to apply different image enhancement techniques such as histogram equalization, thresholding, filtering, and geometric transformations.

## ⚙️ Technologies Used
- Python
- OpenCV
- PyQt5
- NumPy
- Matplotlib

## 🚀 Features
- Load and display an image
- Show histogram
- Histogram equalization
- Thresholding (Binary & Otsu)
- Image filtering (Mean, Gaussian, Median)
- Geometric transformations (Rotation, Cropping, Zoom)
# TP2 - Image Enhancement App

## 📌 Description
This project is a graphical application developed using Python, PyQt5, and OpenCV.  
It allows users to apply different image enhancement techniques such as histogram equalization, thresholding, filtering, and geometric transformations.

## ⚙️ Technologies Used
- Python
- OpenCV
- PyQt5
- NumPy
- Matplotlib

## 🚀 Features
- Load and display an image
- Show histogram
- Histogram equalization
- Thresholding (Binary & Otsu)
- Image filtering (Mean, Gaussian, Median)
- Geometric transformations (Rotation, Cropping, Zoom)

## ▶️ How to Run
1. Install dependencies:
pip install PyQt5 opencv-python numpy matplotlib
2. Run the application:
python main.py

## 📷 Results
The application displays processed images and their histograms in an interactive GUI.
